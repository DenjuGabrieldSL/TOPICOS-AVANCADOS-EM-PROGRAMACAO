# Unidade 5 - Cadastro Acadêmico com TypeScript

## Objetivo

Migrar um cadastro acadêmico modular de JavaScript para TypeScript,
utilizando tipagem estática e modo estrito.

## Tecnologias

- JavaScript
- TypeScript
- Node.js
- ECMAScript Modules

## Funcionalidades

- Cadastro de estudantes.
- Consulta por matrícula.
- Listagem de estudantes.
- Cadastro e validação de notas.
- Cálculo de médias.
- Controle de status de chamados.
- Validação de dados externos com unknown.
- Verificação de tipos em modo estrito.

## Configuração

Instalar as dependências:

npm install

Verificar os tipos:

npm run check

Compilar:

npm run build

Executar:

npm start

## Verificação

O projeto utiliza strict, noImplicitAny e strictNullChecks
para identificar possíveis erros antes da execução.
