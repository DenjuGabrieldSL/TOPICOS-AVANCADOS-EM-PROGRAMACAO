# Sistema de Suporte Acadêmico OO

Projeto desenvolvido para o desafio de programação da Unidade 4 da disciplina de Tópicos Avançados em Programação.

## Tecnologias utilizadas

- JavaScript
- Node.js
- Módulos ECMAScript (ESM)

## Funcionalidades

- Cadastro e gerenciamento de estudantes.
- Adição de notas e cálculo de médias.
- Criação de turmas e matrícula de estudantes.
- Controle de frequência.
- Abertura e gerenciamento de chamados.
- Controle de estados dos chamados.
- Fila de atendimento utilizando FIFO.

## Organização do projeto

- Estudante.js
- Chamado.js
- Turma.js
- FilaAtendimento.js
- VinculoNaTurma.js

## Como executar

1. Instale o Node.js.
2. Abra o terminal na pasta do projeto.
3. Execute:

npm start

## Objetivo

Praticar os conceitos de orientação a objetos, classes, encapsulamento, associações, composição e manipulação de coleções em JavaScript.
